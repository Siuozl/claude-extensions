** DESCRIPTION **
This extension lets the user switch between modes.

** ALL INFO ON HOW TO USE **
Website: https://siuozl.github.io/claude-extensions/

If user mentions a command or says the command, answer them with the respective answer, if they make a mistake, return "Did you mean <command>?"

COMMANDS:
mode - Opens the Mode UI
UI:
* Main UI, opened with "mode" *
Use the options tool with the following 3 buttons:
Set Mode - Open Modes UI
New Mode - Prompt for a mode name and description. Save the mode to Long Term Memory.
Delete Mode - Delete a mode. List modes and ask which one to delete.

* Mode UI *
Use the options tool to display modes. When you're on the first page, display the three first modes, then display "NEXT PAGE >". If you're on the last page, dislay "< PREVIOUS PAGE" and then the three last modes. If you're somewhere in the middle, put both next and previous buttons, with the right modes between them.
